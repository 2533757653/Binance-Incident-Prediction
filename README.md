# Horizon-Incident — 加密事件合约「涨/跌」ML 信号系统

> BTC / ETH 短周期方向预测；**只发信号、不自动下单**。配套实时观察面板 + 桌面/邮件提醒。
> ⚠️ **教育与研究用途，非投资建议。真实优势微弱，请先纸面观察，切勿重仓。**

---

## 🔎 诚实声明（请先读这个）

本项目最有价值的地方是**对自己诚实**：

- 早期回测曾吹到 **74~80% 胜率**，经审计确认是 **数据泄露（前视偏差）**——高周期特征误用了「当前未收盘」的 K 线。**已彻底修复**。
- 修复后的**真实水平**：单币次日/短周期方向的区分力 **AUC ≈ 0.53**；阈值 0.55 时胜率约 **52~54%**，只赌高把握（阈值 ≥ 0.65）约 **55~57%**。
- 事件合约扣掉点差后通常需要 **> 54%** 才保本 → **优势微弱，仅供参考**。

> 一句话：这不是印钞机。它是一个把「弱信号」诚实量化出来、并明确告诉你边界在哪的实验。

---

## ✅ 唯二被证明真正有效的

1. **BTC/ETH 同向协同**：两个币的模型**同向**时才出手，胜率约 **+3~6pp**（可达 58~63%）。
2. **只赌高把握**：提高置信门槛、少而精地出信号，胜率越过保本线。

## ⚙️ 技术要点

- **数据源**：Bybit → OKX → Gate 自动兜底（**无需 Binance，国内可直连**），本地缓存。
- **因果特征**：高周期按真实时钟对齐 + 只用「已收盘」K 线，**训练 == 实盘**，从根上杜绝前视泄露。
- **模型**：XGBoost + walk-forward（过去训练→未来测试）诚实回测；诚实模型见 `proofs/honest/`。

## 🚀 快速开始（Windows）

```bash
pip install -r requirements.txt

# （可选）邮件提醒：复制模板，填入你自己的 QQ 邮箱授权码
cp config/smtp.env.example config/smtp.env      # 然后编辑 config/smtp.env

python train_honest.py        # （可选）用一年数据重训诚实模型；仓库已附带训练好的
scripts/optimised.bat         # 启动 BTC/ETH 协同优化版观察面板
```

> 提示：`.bat` 启动脚本需为 **CRLF** 换行（本仓库 `.gitattributes` 已配置）。关闭窗口即停止。
>
> 🔧 双击若报 `No module named 'xxx'`：是当前 Python 没装依赖。用**你实际运行的那个 Python** 执行 `python -m pip install -r requirements.txt`；或把 `scripts/*.bat` 里的 `set "PY=..."` 改成你 Python 的完整路径。
